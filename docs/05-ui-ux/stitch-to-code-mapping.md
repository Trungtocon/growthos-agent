## Quy tắc đặt ảnh

Đặt file ảnh vào:

```text
public/stitch_ui/<expected_png>
```

Nếu tên file trong máy đang khác, đổi tên theo cột `PNG Source`, hoặc cập nhật `screen-manifest.csv` và `src/data/screens.ts`.
