# PROJECT BIBLE — UIKIGAI AI Workforce OS

## Vision

UIKIGAI AI Workforce OS là hệ điều hành điều phối đội ngũ AI Agent cho doanh nghiệp. Sản phẩm giúp doanh nghiệp thiết lập mục tiêu, tạo dự án, giao ticket, điều phối agent, theo dõi run, review artifact, phê duyệt hành động rủi ro, kiểm soát chi phí và tạo báo cáo.

## Core positioning

Không phải chatbot. Không phải task manager thông thường. Đây là Business Operating System cho đội AI Agent có tổ chức.

## Core flow

```text
Onboarding
→ Company
→ Goals
→ Projects
→ AI Workforce
→ Tickets
→ Runs
→ Artifacts
→ Approvals
→ Governance
→ Cost
→ Reports
→ Integrations
→ Admin
```

## Main user promise

Doanh nghiệp có thể điều hành một đội AI Agent như một phòng ban thật: có mục tiêu, có người phụ trách, có công việc, có quá trình thực thi, có đầu ra, có phê duyệt, có chi phí và có kiểm soát rủi ro.

## Frontend implementation strategy

1. Build consistent AppShell.
2. Build mock-data-driven screens.
3. Implement visual parity from PNG.
4. Keep components reusable.
5. Add later backend integration after UI is stable.

## Main demo story

1. CEO opens Command Center.
2. Sees AI Workforce health.
3. Opens Org Chart to see AI team.
4. Opens Tickets Board.
5. Opens Ticket Detail.
6. Watches Run Console.
7. Reviews Artifact.
8. Approves risky action in Approval Center.
9. Checks Cost Dashboard and Reports.
